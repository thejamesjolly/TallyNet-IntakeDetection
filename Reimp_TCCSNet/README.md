# README for TCCSNet Reimplementation

Reimplementation of code from the paper:
"Temporal-channel convolution with self-attention network for human activity recognition using wearable sensors" 
by Ehab Essa and Islam R. Abdelmaksoud [^EssaTCCSNet].


## Repository Contents

The model architecture for the PyTorch model is defined in `TCCSNet_Classifier.py`.

Training is managed by `Train_TCCSNet.py` and evaluation results are generated by `Eval_TCCSNet.py`, with details on how to run them listed below.

Example models for each dataset are provided in the `Models/` directory.


## TO TRAIN MODELS

To train a model, use the following prompt in the command line.

`python Train_TCCSNet.py [FolderName] [Cut] [Stride] [DATABASE_Flag] [FoldSegFlag] [FoldNumber] [TotalFolds] [OPTIONAL_ARGS]`

- Train_TallyNet.py
	* Python Script to train TallyNet model

- `FolderName`
	* Output folder location to store all files generated with the specific fold and model currently training

- `Cut`
	* Total duration of the window used as an input to the model
	* Units are in seconds

- `Stride`
	* Step which the dataset will slide the window forward through the motion data to generate the next example
	* Units are in Seconds

- `DATABASE_Flag` 
	* Flag used to select which dataset the model is working with
		- 1 = Dnd OREBA One-Handed
		- 2 = Dnd OREBA Two-Handed
		- 3 = Dnd Clemson
		- 4 = Dom OREBA One-Handed
		- 5 = Dom Clemson

- `FoldNumber`
	* Number of the fold used in k-fold validation (ranging from 1 to `TotalFolds`) used for training and testing split

- `TotalFolds`
	* Total number of folds used in k-fold validation



- `OPTIONAL ARGS`
    * Values can be modified, but have default values in training
    * `--arch [ModelArchFlag]`
    	- Model Architecture ID based to ModelSelect.py to return hidden layer structure of the model
            * 1 = CSNet (Default Value)
            * 2 = TCCSNet
    * `--fold-seg [FoldSegFlag]`
    	- Bool determining whether the k-fold validation is contiguous blocks or striped through all examples
    		* 0 = Block Segmentation
    		* 1 = Striped Segmentation (Default Value)
    * `--resamp [ResampFlag]`
    	- Resampling Rate in Hertz to which all datasets will be interpolated to match.
    	- Lower Sampling rate decreases memory and computation, but also model capabilities on harder datasets.
    	- 15 Hz is the observed "knee" in F1 vs Sampling Rate where performance is maintained well while reducing complexity



- Example
	* `python Train_TCCSNet.py ExampleModel/models/fold1 4 0.5 2 1 5 --arch 1 > "ExampleModel/training_fold1.txt`











## TO EVALUATE MODELS

To evaluate a model, run the following command in the command line.

python Eval_TCCSNet.py Models/"$Folder_Name"/models/fold1_best.pt $DatabaseFlag 1 5 --stride $STRIDE_sec --trigger $Thresh --arch $ModelArchFlag --add-eval $EvalMethod --tol $Tol > Results/"$Folder_Name"_e"$EvalMethod"_t"$Tol"_trig"$ThreshName"_Results.txt

`python Eval_TCCSNet.py [Folder_Name] [DatabaseFlag] [FoldNumber] [TotalFolds] [OPTIONAL_ARGS] [FoldSplitFlag] [Cut] [Stride] [ResampRate] [WinTol]`

- Eval_HeydReimp.py
	* Python Script used for evaluation

- `FolderName`
	* Name of the folder which contains the model .pb file
	* Should be the same as the training folder but with an additional `/models/foldN` appended to it, where N is the fold number
	* Does not end in a `/`

- `DATABASE_Flag`
	* Flag used to select which dataset the model is working with
		- 1 = Dnd OREBA One-Handed
		- 2 = Dnd OREBA Two-Handed
		- 3 = Dnd Clemson
		- 4 = Dom OREBA One-Handed
		- 5 = Dom Clemson

- `FoldNumber`
	* Number of the fold used in k-fold validation (ranging from 1 to `TotalFolds`) used for training and testing split

- `TotalFolds`
	* Total number of folds used in k-fold validation

- `OPTIONAL_ARGS`
    * `--stride [float]`
    * `--cut [int]`
    * `--arch [int]`
    * `--resamp [int]`
    * `--fold-seg [int]`
    * `--save-preds [int]`
    * `--save-gts [int]`
    * `--trigger [int]`
    * `--add-eval [int]`


- `FoldSegFlag`
	* Bool determining whether the k-fold validation is contiguous blocks or striped through all examples
		- 0 = Block Segmentation
		- 1 = Striped Segmentation

- `Cut`
	* Total duration of the window used as an input to the model
	* Units are in seconds

- `Stride`
	* Step which the dataset will slide the window forward through the motion data to generate the next example
	* Units are in Seconds


- `ResampFlag`
	* Resampling Rate in Hertz to which all datasets will be interpolated to match.
	* Lower Sampling rate decreases memory and computation, but also model capabilities on harder datasets.
	* 15 Hz is the observed "knee" in F1 vs Sampling Rate where performance is maintained well while reducing complexity

- `Win_tol_sec`
	* Tolerance (in seconds) to allow when matching detections to gesture ground truth window using Kyrit_Pt2Window evaluation


- Full Example
	* `python Eval_TallyNet.py TallyNet_Example_THO/models/fold4 4 5 1 15 1 2 15 12 >> Example_THO_Results.txt`
